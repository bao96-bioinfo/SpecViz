|                                                                              |
| (Node 4)                                                                     |

| Repeating prediction with identical inputs must reproduce the same output.   |

+------------------------------------------------------------------------------+

| Diagram 1, Node 5: Evaluate the results                                      |
|                                                                              |
| (Node 5)                                                                     |
| <-- Node 4: saved predictions                                                |
| Compare the saved predictions with answers kept out of training. Report      |
| error and uncertainty, including the number of people evaluated. Keep the    |
| evaluation table so the notebook can reproduce every reported number. The    |
| acceptable error threshold is undecided; do not describe the model as        |
| accepted.                                                                    |
| Files: [7]                                                                   |
